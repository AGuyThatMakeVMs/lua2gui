Lua 2 Gui reads .lua and .luau files, extracts supported GUI creation statements, and preserves the original source as an optional LocalScript in the exported model. The browser never executes your script. When imported into Roblox Studio, an included LocalScript can run, so only export and run code you trust. Dynamic UI, loops, functions, and event callbacks are preserved in the script but cannot be faithfully simulated by the static preview.

Free Roblox UI Converter for Roblox Studio

Lua 2 Gui is a free, browser-based Roblox UI converter. It reads supported Lua and Luau interface code, builds a visual preview of recognized GUI objects, and exports an editable .rbxmx model that you can import into Roblox Studio. You can use it on a phone, tablet, or computer without installing a converter app.

What can Lua 2 Gui convert?

The converter is designed for common Roblox interface code that creates objects with Instance.new() and assigns supported properties. It recognizes interface elements such as ScreenGui, Frame, TextLabel, TextButton, TextBox, ImageLabel, and ScrollingFrame, as well as UI components such as UICorner, UIStroke, UIListLayout, UIGridLayout, and UIPadding.

  • Paste code or open a .lua or .luau file.
  • Preview the supported interface and inspect the object hierarchy.
  • Review warnings when a statement or property is not supported by the static converter.
  • Download an .rbxmx model, a ZIP containing the model, or the original source file.
  • Check the layout in desktop, phone, and tablet preview modes.

How to use the Roblox GUI converter

Paste a Roblox UI script into the Lua source box, or choose a local Lua/Luau file. Select Convert to build the preview and model. Review the warnings, choose a file name, and download the RBXMX file. In Roblox Studio, insert the exported model into your project and inspect it before publishing.

What are the converter's limits?

Lua 2 Gui is a static code converter, not a Roblox game runtime. It does not execute arbitrary Luau in the browser. Dynamic behavior such as loops, functions, event callbacks, and code that creates UI conditionally cannot be fully reproduced in the visual preview. The original source can be exported separately, and unsupported statements are reported where detected. Always review exported content in Roblox Studio.

Frequently asked questions

Is Lua 2 Gui free?

Yes. The browser converter is free to use and does not require an account.

Does it work on mobile phones?

Yes. The website layout adapts to mobile phones, tablets, and desktop browsers. Large or complex scripts may be easier to review on a larger screen.

Does it run my Roblox script?

No. The browser does not execute pasted Luau. It analyzes supported declarations to create a static preview and an RBXMX model.

Can it convert every Roblox UI library?

Not yet. The current converter focuses on direct Roblox instance creation and supported property assignments. Framework-specific syntax needs a dedicated parser or adapter.

Where can I learn about Roblox interface objects?

Read the official Roblox Creator Hub UI documentation for ScreenGui, Frames, text objects, layouts, and interface behavior.
