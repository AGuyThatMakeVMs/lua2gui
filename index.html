Lua 2 Gui builds a model from supported Instance.new declarations. LocalScript, Script, and ModuleScript instances are kept in the exported hierarchy, including their Source when provided as a Lua long-bracket string ([[...]]). Scripts are packaged, never executed by this website. Dynamic code that creates UI at runtime still needs to be tested in Roblox Studio. Unparented UI objects are placed inside an automatic ScreenGui.
